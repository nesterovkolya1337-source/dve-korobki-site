# Первое размещение в Selectel через консоль

Подготовлено 05.10.2026. Это установка HTTP-preview по IP, не запуск домена.

- Сервер: `87.228.105.192`, `dvekorobki_server`, ru-9a.
- Скрипт: `scripts/deploy-selectel-preview.sh`, запуск root в консоли Selectel.
- Исходники сайта закреплены на `138c05f21e26466202b0c8f3bc17444ab52918bc`.
- Сборка с пустым BASE_PATH и SITE_URL по IP. Перед размещением выполняется `npm run check`; форма должна оставаться отключённой.
- Устанавливаются Ubuntu-пакеты git, Node.js, npm, Nginx, curl и CA. Node должен быть версии 20 или выше.
- Скрипт отказывается работать на другом IP, при занятом порте 80 или уже существующей установке. Он не изменяет SSH, VPN, DNS, группы безопасности и чужие конфигурации Nginx.
- Источник хранится в `/opt/dve-korobki/source.*`, статический релиз — `/var/www/dve-korobki/releases/`, ссылка — `/var/www/dve-korobki/current`.
- Конфигурация — `/etc/nginx/conf.d/dve-korobki-preview.conf`. HTTP-preview получает `X-Robots-Tag: noindex, nofollow`; access log этого виртуального хоста выключен. Это не защита от просмотра и не подтверждение юридической готовности.
- При ошибке активации удаляются только созданные конфигурация и ссылка current; установленные пакеты, исходники и релиз сохраняются.
- После READY нужно независимо открыть IP, сверить `/deployed-revision.txt`, фотографии, маршруты и мобильный вид. Успешная локальная проверка на ВМ не подтверждает внешнюю доступность.
- Для домена нужны его точное имя, DNS, HTTPS и новая сборка с правильным SITE_URL; снятие noindex — отдельный шаг после готовности к публикации.

Синтаксис маршрутизации: [официальная документация Nginx try_files](https://nginx.org/en/docs/http/ngx_http_core_module.html#try_files).
