# Паспорт проекта «ДВЕ КОРОБКИ»

Сводка от 28.09.2026. Основание: прямые сообщения в текущем диалоге, найденные решения пользователя из прошлых чатов и актуальный GitHub-код. Хронология и ограничения полноты — в `CHAT_HISTORY.md`.

## Задача и специализация

Сайт профильного автосервиса должен помочь посетителю выбрать направление ремонта, понять порядок работ и обратиться в сервис. Специализация: DSG / S-Tronic, PowerShift, китайские DCT и двухмассовые маховики. География проекта — Санкт-Петербург и Москва. Не расширять позиционирование до ремонта всех АКПП или вариаторов.

Основная логика: диагностика → объяснение причины и вариантов → согласование работ/стоимости → ремонт → проверка. Точные гарантии, цены, адреса и юридические сведения берутся из подтверждённых бизнес-данных, а не из рекламных референсов.

## Текущая архитектура

Статический сайт на HTML/CSS/JavaScript с генератором на Node.js ES modules. Нет Next.js, React, API-сервера или базы данных в текущем репозитории. Вёрстка и компоненты — `src/lib/render.mjs`, иконки — `src/lib/icons.mjs`, стили — `src/styles/main.css`, поведение — `src/scripts/site.js`. `scripts/build.mjs` формирует `dist/`; вручную его не редактировать.

22 маршрута покрывают главную, диагностику, мехатроник, сцепление, адаптацию, маховики, DQ200/DQ250/DQ500/DL501, DPS6/MPS6, шесть направлений азиатских DCT, услуги, цены, контакты и «О нас». Точный список не дублируется: см. `ROUTES.md` и JSON.

Публикация: GitHub Actions → GitHub Pages. Push в `main` запускает сборку и выкладку; PR запускает проверки и сохраняет сборочный артефакт, но сам по себе не публикует обновление на Pages.

## Дизайн и изображения

- Продолжать текущие блоки и согласованные кадры; не создавать новую главную при смене чата.
- Палитра действующей реализации: белый, чёрный, серый, красный акцент. Сохранять типографику и систему SVG-иконок.
- Шапка — компактный знак; первый экран главной — большой фирменный цветной знак. Служебная иллюстрация не выдаётся за фотографию определённой модели.
- Пользователь требует реальные изображения агрегатов. Не подменять их AI-коробками; модельные индексы подписывать только при проверенном соответствии.
- Предоставленные фото прошлого сервиса разрешены пользователем. Корректная привязка: практика команды, без утверждения, что это нынешняя точка в конкретном городе.
- Снимки IMG_7231, IMG_7242, IMG_7251, IMG_7255 добавлены в отдельный PR #1; текущий статус в `CURRENT_STATE.md`.

## Что обсуждалось, но не является готовой функцией

Квиз, карта ошибок, база знаний, отдельные страницы по симптомам/автомобилям, `/ai-info/`, локальные страницы городов, карты и расширенная аналитика. В найденных сводках степень утверждения части идей противоречива. Считать их кандидатами на развитие, а не заданием добавить всё сразу. Новые маршруты потребуют согласованного объёма и изменения валидатора, который сейчас ожидает 22 страницы.

Интерес к конкурентам в Google/Яндексе и Москве/СПб восстановлен. Полного актуального отчёта с проверенными URL и выводами в репозитории нет; не воспроизводить рейтинги или «лучшие практики» по памяти. Регулярную автоматизацию мониторинга эта передача не создаёт.

## Приоритет достоверности

Новые прямые указания владельца → проверенный текущий код и состояние сервиса → подтверждённые решения проекта → датированная история → предложения. Если история противоречит коду, явно фиксировать расхождение, а не переписывать ни историю, ни факт реализации. ASAYA даёт опыт процесса, но её требования магазина не становятся требованиями автосервиса.
