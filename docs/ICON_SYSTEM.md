# Icon system

The site uses a custom inline SVG icon set from `src/lib/icons.mjs`.

## Visual rules

- 24 x 24 coordinate grid.
- 1.9 px rounded stroke.
- No embedded colors: icons inherit `currentColor`.
- Compact square or circular containers use the same red accent and subtle shadow.
- Technical icons are schematic and must not imply a specific gearbox model.
- Every service card uses a semantic icon selected from its title, description and route.

## Service icons

- `diagnostic`: scanner and signal graph.
- `transmission`: generic transmission housing.
- `mechatronic`: control board and contacts.
- `clutch`: concentric clutch assembly.
- `adaptation`: calibration sliders.
- `flywheel`: generic flywheel with mounting points.
- `wrench`: mechanical service.
- `shield`: warranty and protection.

## Interface icons

- `arrow`, `menu`, `close`.
- `phone`, `pin`.
- `check`, `clock`, `ruble`, `award`, `target`, `gear`.

Real verified photography will replace temporary service hero graphics later. The icon system remains as navigation and content support after photography is added.
