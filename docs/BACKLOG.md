# Очередь работ

Обновлено 28.09.2026. Сначала сверить `CURRENT_STATE.md` и GitHub. Это рабочая приоритизация восстановления проекта; обсуждавшиеся идеи не превращаются автоматически в обязательный объём.

Дополнение: визуальная проверка фотоэтапа на 390/1440 выполнена в рабочей ветке, исправления обращения подготовлены. Новое состояние и оставшиеся юридические зависимости — [CURRENT_STATE](CURRENT_STATE.md) и [RF_READINESS](RF_READINESS.md). До подтверждённой инфраструктуры и документов использовать телефонную запись. Не включать старый FormSubmit одной переменной окружения.

| Приоритет | Задача | Готово, когда | Зависимость |
|---|---|---|---|
| 1 | Завершить фотоэтап PR #1 | Главная, диагностика, сцепление, мехатроник, «О нас» проверены на 390/1440; кадры читаемы; нет чёрных полей/переполнения; CI зелёный | Доступный браузерный preview |
| 2 | Проверить оставшиеся реальные изображения | Для каждого выбранного кадра известны источник, модель или нейтральная подпись, назначение, допустимый crop; manifest обновлён | Оригиналы и проверка маркировки |
| 3 | Довести текущий frontend | Меню, кнопки, якоря, фокус клавиатуры, формы и основные адаптивные состояния работают; готовые блоки сохранены | Текущий код + доступные согласованные кадры |
| 4 | Убрать устаревший служебный текст из публичных страниц | Нет формулировок для разработчика вроде «в макете заявлены»; неизвестные факты не выдуманы | Проверка всех 22 маршрутов |
| 5 | Закрыть бизнес-данные запуска | Подтверждены адреса, оператор/реквизиты, цены либо способ расчёта, гарантия, каналы связи; единый JSON | Владелец |
| 6 | Довести документы и обращение в сервис | Документы соответствуют данным владельца; формы ведут на них; обработаны успех/ошибка; согласованный реальный тест доставлен | Бизнес-данные; разрешение на реальную отправку |
| 7 | Сверить SEO и публикацию | title/canonical/schema/robots/sitemap соответствуют реальным страницам/географии; известны релиз, URL и способ отката | Финальные данные и выбранная публикация |

## Обсуждалось для следующей очереди

Квиз, симптомы/коды ошибок, база знаний, реальные кейсы, дополнительные страницы моделей и городов, карты, аналитика, мониторинг конкурентов. Для каждого направления сначала определить результат и объём; не добавлять весь список за один проход. Не считать старые предложения внедрёнными.

## Что не включено

Корзина, кабинет, SMS-вход, платёжный шлюз, CDEK Fulfillment, склад, ecommerce-аналитика и магазинные акции ASAYA. Новый framework или backend без конкретной потребности также не является текущей задачей.
