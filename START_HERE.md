## Подключение в Codex

Используй существующий репозиторий `nesterovkolya1337-source/dve-korobki-site`. Основная ветка — `main`; незавершённые изменения сверяй по `docs/CURRENT_STATE.md` и открытым PR. Не создавай другой репозиторий с похожим названием.

28.09.2026 в Codex Cloud создано окружение `dve-korobki-site` и запущен [первый чат с объединённым контекстом](https://chatgpt.com/codex/cloud/tasks/task_e_6abac98483188320b1ed7ce789d77532) на ветке `main`. Ссылка требует входа в аккаунт владельца. Это новая задача передачи контекста, не импорт старых переписок.

Для локального Codex открой актуальную папку этого репозитория. Для облачной среды выбери тот же GitHub-репозиторий и нужную ветку. Наличие папки или репозитория не означает, что старые переписки появились в списке чатов: эти документы сохраняют рабочие знания отдельно от истории интерфейса.

Среда: Node.js 20+ (CI использует 22), npm. Runtime-зависимостей нет; установка пакетов для текущей сборки не нужна. Команды:

```bash
npm run check
npm run dev
```

Локальный адрес: `http://localhost:4321`. Для проверки путей GitHub Pages: `BASE_PATH=/dve-korobki-site npm run check` (синтаксис bash). Эта команда не публикует сайт.
